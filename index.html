Comparing Representations for Event Camera-based Visual Object Tracking

Publisher: Mohamad Alansari 100061914
Supervised By: Prof. Jorge Dias

Background

Event cameras detect pixel-level intensity changes asynchronously, enabling high-speed motion capture. Advantages include low power consumption and motion blur immunity, but they are less effective for static scenes and lack fine texture details. Hybrid systems that combine RGB and event data are promising but underexplored in terms of representation analysis.

Problem Statement

  • Many prior hybrid trackers use arbitrary event representations without rigorous comparison.
  • The study identifies the need for systematic evaluation of event-based representations specifically for tracking tasks.
  • It emphasizes the importance of choosing the right event encoding format.

Objectives

1. Evaluate four event representations: Event Frame (EF), Voxel Grid (VG), Pseudo-Frames (PS), and Event Spike Tensor (EST).

2. Deploy them across several datasets and tracking models.

3. Propose a unified framework for fusing RGB and event data effectively.
Propose a Visible-Event Tracker that:

  • Effectively leverages the strengths of both RGB and event modalities
  • Maintains generalization across a wide range of event data representations
  • Supports flexible integration of different event representation methods (e.g., VG, EF)

4. Benchmarks

  • Conduct a comprehensive evaluation of 3 selected trackers using 4 distinct event representations
  • Evaluation Metrics: Success (S), Normalized Precision (NP), and Precision (P)
  • Provide practical recommendations for selecting event representations based on use case
  • Provide Future Work

Input Representation

  • Describes the mathematical model behind event generation
  • Events are triggered based on a threshold change in log-intensity
  • Each event is represented as a tuple: (x, y, timestamp, polarity)

Event Representations

  • EF: Accumulates events into 2D image-like frames (fast, simple, but no time order)
  • VG: Uses a 3D voxel grid to store events (preserves temporal data, but memory-heavy)
  • PS: Binary frames filtered for noise (fast, efficient, but loses detail)
  • EST: Differentiable tensor with time bins and polarity channels (most expressive, but complex and costly)

Tested Models

  • Three trackers were evaluated: MambaEVT, HDETrack, and CEUTrack
  • Each was tested with all four event representations
  • Benchmarks were performed on VisEvent and LaSOT datasets

Proposed Unified RGB-Events Tracking Framework

  • Early fusion: Cross-attention between RGB and event features before feeding to a transformer
  • Aligns motion (events) and texture (RGB) cues early
  • Enhances modality-aware feature selection
  • Improves robustness in fast or blurry scenarios

Evaluation Metrics

  • Success (S): Based on intersection over union (IoU) of predicted vs. ground truth boxes
  • Precision (P): Distance between predicted and actual center points
  • Normalized Precision (NP): Precision adjusted for object size
